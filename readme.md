# 🦋 moth

## Purpose

Create HTML structured web-pages using C++ via emscripten/wasm.

## Folder structure

```
moth/
samples/
emsdk/
```

* *moth* is the folder containing the C++ moth library data
* *samples* is the folder container moth samples
* *emsdk* is the folder where you need to install [emscripten](https://emscripten.org/)
